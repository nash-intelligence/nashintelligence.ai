# nashintelligence.ai

Public website for Nash Intelligence.

## Development

```bash
npm install
npm run dev
```

The local dev server runs at `http://localhost:16173`.

## Build

```bash
npm run lint
npm run build
```

The site uses the Next.js static-export setup copied from `knowledgefund.co`, with Nash-specific design assets from `nashintelligence.ai-design`.
